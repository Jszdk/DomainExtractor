# 域名提取器

浏览器插件，从备案查询网站一键提取备案域名。

## 功能

- 自动点击详情按钮，提取备案域名（支持标准域名和IP地址）
- 支持当前页提取和自动翻页提取所有域名
- 结果去重，导出为文本或JSON

## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `beian-extractor-plugin` 文件夹

## 使用

1. 访问备案查询网站，搜索目标单位
2. 等待结果加载完成
3. 点击插件图标
4. 选择「提取当前页域名」或「提取所有页域名」
5. 复制或保存结果

## 输出格式

**文本**（每行一个）:
```
example.com
example.edu.cn
192.168.1.1
```

**JSON**:
```json
["example.com", "example.edu.cn", "192.168.1.1"]
```
