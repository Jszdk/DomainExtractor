# 备案信息提取器 (Beian Extractor)

一个浏览器插件，用于从工信部备案查询网站提取备案域名信息。

## 功能

- 自动识别备案查询结果页面
- 一键提取备案域名、备案号、主办单位等信息
- 支持导出为 Markdown 表格、JSON、CSV 格式
- 数据复制到剪贴板，方便后续使用

## 安装方法

### Chrome / Edge 浏览器

1. 打开浏览器扩展管理页面：`chrome://extensions/` 或 `edge://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本插件所在的文件夹

### Firefox 浏览器

1. 打开 `about:debugging`
2. 点击「此 Firefox」→「临时载入附加组件」
3. 选择本插件文件夹中的 `manifest.json` 文件

## 使用方法

1. 访问 [工信部备案查询网站](https://beian.miit.gov.cn/#/Integrated/recordQuery)
2. 在搜索框中输入企业名称（如"南开大学"）
3. 完成验证码验证，点击搜索
4. 等待备案结果加载完成
5. 点击浏览器右上角的「备案信息提取器」图标
6. 点击「提取备案数据」按钮
7. 选择导出格式（Markdown / JSON / CSV）

## 输出示例

### Markdown 表格
| 域名 | 备案号 | 主办单位 | 性质 | 审核时间 |
|------|--------|----------|------|----------|
| nankai.edu.cn | 津ICP备xxx号 | 南开大学 | 事业单位 | 2020-01-01 |

### JSON
```json
[
  {
    "domain": "nankai.edu.cn",
    "icp": "津ICP备xxx号",
    "organizer": "南开大学",
    "type": "事业单位",
    "date": "2020-01-01"
  }
]
```

### CSV
```csv
域名,备案号,主办单位,性质,审核时间
nankai.edu.cn,津ICP备xxx号,南开大学,事业单位,2020-01-01
```

## 注意事项

- 使用本插件前，请确保已在页面中完成查询并显示结果
- 本插件仅提取页面上已显示的备案信息，不涉及自动化查询
- 请合法合规使用本工具

## 常见问题

**Q: 提取不到数据？**  
A: 请确保：
1. 页面已加载备案查询结果
2. 页面显示的是数据表格（而非查询表单）
3. 刷新页面后重试

**Q: 数据格式不对？**  
A: 备案网站的页面结构可能会更新。如果遇到问题，请检查浏览器控制台是否有错误信息。
